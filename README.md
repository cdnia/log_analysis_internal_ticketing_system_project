# Project title : Log Analysis of an internal ticketing system with a python script
## Description of the project
We consider an internal ticketing system that is used by several teams in an enterprise.This system logs
events in a file called `syslog.log`. The file `syslog.log` contains useful information about tickets
such as who submitted the ticket, the ticket type (ERROR or INFO), when it was submitted, the ticket 
message, etc.

We write a python script called `generate_reports.py` that analyze the `syslog.log` file and produce 
reports depending on the information was extracted.<br>  
## Goal of the project
The role of our script is to generate two reports from the `syslog.log` file :
- the first report is a file called `error_message.csv`. Within that file there is a record of error
messages and their corresponding counts sorted with these criteria : the most common error to the least 
common error, without referencing users.
- the second report is a file called `user_statistics.csv`.Within that file there is a record of usage 
statistics for the service (an inventory of every user who have utilized the system which also specifies 
the number of informational and error messages generated by each user, sorted by username).
In summary, the objective of the single script is to generate the two reports on a recurring basis automatically without 
any user intervention.We can accomplish that by using cron jobs in a linux environment.
## HOW TO RUN IT
- First check that the `syslog.log` file and the file `generate_reports.py` are in same directory.
- The python version used in this project is 3.11.2, you can install a python version (note: install at least Python 
3.11) by following instructions to install the latest version of python for your OS in the 
[python website](https://www.python.org/downloads/).
- You can run the script by doing `python generate_reports.py` or `./generate_reports.py` (in a linux environment).
- Yan can use cron jobs to run the script periodically and automatically.
For example, you can put this line in a crontab to execute the script at 4 PM (16:00) every Sunday:
0 16 * * 0 /path_to_the_script/generate_reports.py
Note : replace "path_to_the_script" by the actual full path to the directory containing the script.
